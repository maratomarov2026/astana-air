# Воздух Астаны

Сайт о качестве воздуха в Астане: индекс сейчас, совет, график за 5 суток (3 назад, 2 вперёд) и лучшее время для прогулки. Подробности в `PRD.md`.

Node.js 18+, внешних зависимостей нет.

## Запуск

```bash
node server.js        # http://localhost:3000
npm test              # автотесты сервера
```

Порт задаётся переменной `PORT`.

## Docker

```bash
docker build -t astana-air .
docker run -p 3000:3000 astana-air
```

## Адреса

| Адрес | Что отдаёт |
|---|---|
| `GET /api/air` | Нормализованные данные Open-Meteo (кэш 10 минут; при сбое источника последний кэш с `stale: true`; без кэша 502) |
| `GET /healthz` | `ok` |
| прочее | статика из `public/` |

## Структура

- `server.js` — сервер, запрос к источнику, нормализация (`normalize`), кэш, статика, заголовки безопасности
- `public/` — `index.html`, `style.css`, `app.js`
- `test/server.test.js` — тесты

## Источник данных

[Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) (модель CAMS). Это модельный расчёт, не показание датчика. Бесплатный тариф рассчитан на некоммерческое использование. Формат ответа взят из документации и ещё не проверен на живом запросе: если что-то не отображается, начните с функции `normalize` в `server.js`.
