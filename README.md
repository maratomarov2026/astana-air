# Воздух Астаны

Сайт о качестве воздуха в Астане: индекс сейчас, график за 5 суток (3 назад, 2 вперёд), лучшее время для прогулки, шкала с советами. Подробности в PRD.

Node.js 18+, без внешних зависимостей. Данные: [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) (модель CAMS), ключ не нужен, бесплатный тариф только для некоммерческого использования.

## Запуск

```bash
node server.js        # http://localhost:3000
npm test              # автотесты сервера
```

Порт задаётся переменной `PORT`.

Docker:

```bash
docker build -t astana-air .
docker run -p 3000:3000 astana-air
```

## Адреса

- `GET /api/air` — нормализованные данные (кэш 10 минут; при сбое источника отдаётся кэш с `stale: true`, без кэша — `502`)
- `GET /healthz` — `ok`
- остальное — статика из `public/`

## Структура

| Файл | Назначение |
|---|---|
| `server.js` | HTTP-сервер, запрос к источнику, нормализация (`normalize`), кэш, статика, заголовки безопасности |
| `public/` | `index.html`, `style.css`, `app.js` |
| `test/server.test.js` | автотесты |

Чтобы сменить источник данных, достаточно переписать `normalize()` и `SOURCE_URL` в `server.js`.

## Что ещё не проверено

Формат ответа настоящего Open-Meteo взят из документации; внешний вид в реальных браузерах и доступность вручную не проверялись.
